# Coin Flip Streak & Probability Simulator

A Python simulation that flips a fair coin 10,000 times to explore probability, the Law of Large Numbers, and consecutive streak lengths.

## Features
- Simulates 10,000 random coin flips (`"heads"` or `"tails"`) using Python's built-in `random` module.
- Calculates the total count and overall percentage of heads landed.
- Tracks the active consecutive streak and records the all-time longest streak of heads.

## Example Output
```text
Heads: 5035/10000 (50.3%)
Longest streak of heads: 13
```
